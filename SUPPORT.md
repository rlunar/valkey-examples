# Support

Valkey Examples provides maintained educational journeys, not production
support or architecture certification.

Use a public issue for:

- a documented example journey that no longer works;
- incorrect expected output;
- compatibility regressions;
- broken documentation; or
- a proposal for a new example.

Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

When reporting a failure, include the capsule ID, commit, operating system,
runtime version, Valkey version, command executed, and relevant sanitized logs.

Archived examples are retained for provenance only and receive no compatibility
or maintenance commitment.
