# Capability Categories

Example capsules are organized by what a user wants to learn about Valkey.

The initial controlled vocabulary is:

- `caching`
- `data-structures`
- `messaging-and-streams`
- `migrations-and-integrations`
- `operations`
- `rate-limiter`
- `search`

Adding or renaming a category requires maintainer approval. Frameworks, vendors,
clouds, and model providers are not capability categories.
