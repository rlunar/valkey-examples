# Valkey Examples Catalog

The catalog organizes independently runnable educational material by learning
goal and expected learner depth.

## Language

**Capsule**:
An independently runnable, copyable, and removable educational example with
its own application behavior, dependencies, documentation, and lifecycle.
_Avoid_: Project, sample folder

**Level**:
A capsule's required learning-depth classification, based on prerequisite
knowledge and conceptual reasoning rather than code size or runtime resources.
_Avoid_: Difficulty, complexity score

**L100 — Beginner**:
Introduces one core Valkey concept through guided commands and assumes no prior
Valkey experience.

**L200 — Intermediate**:
Combines several concepts in a small application and assumes basic familiarity
with Valkey commands and a client library.

**L300 — Advanced**:
Explains concurrency, transactions, distributed topology, failure behavior, or
material operational tradeoffs.

**L400 — Expert**:
Requires deep distributed-systems, performance, or security expertise and
explores complex cross-capability design.

**L500 — Maintainer**:
Teaches internals, extension, compatibility, governance, or ongoing maintenance
of Valkey ecosystem and repository modules.
